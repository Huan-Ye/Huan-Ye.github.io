第二卷：AI Agent 与社会结构

副标题：从产业重组到职业入口、分配、家庭、地区与公共信任
日期：2026-08-05
证据索引：[Sxx] 对应 02_source_log.md；上游产业机制见 19_macro_industry_real_economy_volume.md 与 20_industry_transformation_matrix.md。

第一页：社会 House View

AI Agent 的社会影响不会主要通过“一个机器人夺走一份工作”发生，而会沿着更慢、更隐蔽的路径扩散：

企业先减少初级招聘、外包和空缺补充 → 工作中的训练任务减少 → 进入稳定职业所需的家庭支持、教育信誉和人际网络上升 → 工资与财富差异通过职业入口而非同岗工资扩大 → 消费、迁移、婚育和地区财政发生滞后变化 → 企业和政府再造培训、认证、公共服务与安全制度。

当前证据支持其中前半段，但尚不足以确认全部长期后果。美国 Census 的企业调查显示 AI 导致的企业人数下降仍少见 [S34]；另一份行政数据研究却发现，最暴露行业中 22—24 岁人员的招聘在 ChatGPT 后相对下降约 9%，十个季度后就业相对下降约 12% [S72]。这两个结果可以同时成立：冲击先压缩入口，并不要求企业先解雇存量员工。

社会层面的主要矛盾也不是简单的“高技能赢、低技能输”。任务实验中低经验者往往获得更大即时收益 [S61][S74]，这可缩小在岗表现差距；但若企业因此减少初级职位，低家庭资本者更难进入职业并积累经验。Agent 可能在企业内部民主化技能，却在企业入口重新提高门槛。

五项主要判断

  1. 职业会先被重新分层，而不是整体消失。 同一职业内部会分成任务执行者、Agent 编排者、例外处理者、责任签字者和关系／现场角色。
  2. 初级岗位与训练链是最大社会脆弱点。 企业节省的是低风险、重复、可复核任务，而这些任务正是新人学习行业的入口。
  3. 工资差异与财富差异可能方向不同。 同岗低经验者因 Agent 获益可压缩工资差距；模型、云、数据、渠道和企业股权的回报则可能扩大财富集中 [S58][S59]。
  4. 家庭将成为转型期的隐性保险人。 可承受无薪学习、反复求职、设备订阅、迁移和创业试错的家庭拥有更大选择集，冲击可能沿代际传递。
  5. 公共服务的核心不是自动化率，而是可申诉性。 政府 Agent 可降低材料和查询成本，但错误、数字排除与责任不清会把节省转化为线下补救和信任损失 [S79]。

总体置信度为中低：劳动任务和早期招聘已有证据，家庭、婚育、地区与代际结果主要是机制推断，必须用纵向数据继续验证。

1. 从行业变化到职业变化

1.1 职业不是任务的简单总和

ILO 估计全球约四分之一劳动者所在职业有某种生成式 AI 暴露，最高暴露类别约占全球就业 3.3%，并强调多数职业更可能转型而非完全替代 [S55]。暴露测量的是技术能否处理任务，不包含企业采用、工资、客户需求、许可、责任和物理执行。ILO 进一步明确，暴露指数应作为预警信号，而非岗位损失预测 [S56]。

一个职业能够继续存在，可能因为至少一项不可压缩功能：

  • 对最终结果承担法律或专业责任；
  • 在信息不完整时做情境判断；
  • 获取客户信任、安抚、谈判或照护；
  • 进入现场并操作物理环境；
  • 在组织内分配资源和解决冲突；
  • 代表利益群体形成合法决策。

因此，Agent 会先拿走职业里的“制作”部分，把人推向判断、关系、现场和责任。职业名称可能不变，但人数、晋升路径、技能组合和议价能力会变化。

1.3 新职业怎样真正形成

一项新任务要成为职业，必须同时满足：工作量持续、错误代价足够高、需要独立专业判断、付款方明确、能力可认证。按此标准，较可能制度化的不是短期“提示词工程师”，而是：

  • Agent 工作流设计与运营负责人；
  • Agent 身份、权限、预算和密钥治理；
  • 模型／工作流评测、证据与来源核验；
  • 异常接管、事故调查和责任接口；
  • 行业数据治理与语义工程；
  • 人机培训、模拟任务与职业认证设计；
  • 机器可读商品、合同和公共规则维护；
  • 数字替身、内容来源与授权管理；
  • 现场 Agent 集成和远程运营。

中国的新职业制度可通过官方职业分类、标准和继续教育推进 [S64][S65]；美国更可能先由企业岗位、行业认证、保险和诉讼实践形成，再逐渐标准化。

2. 初级岗位、训练与职业阶梯

2.1 为什么初级岗位先受影响

企业不会先让 Agent 负责最复杂、最有责任的任务，而会先处理标准化、可复核、失败成本低的工作。这些恰好是初级员工传统上承担的资料收集、初稿、测试、报表、排程和客户分流。企业从成本角度看是在删除低价值工作；职业体系从时间角度看，却可能删除“未来高价值人员的训练材料”。

美国行政数据对高暴露行业早期职业招聘的相对下降 [S72] 提供了第一类现实信号，但因疫情、远程办公、教育和货币政策等并发变化，不能把全部降幅归因于 AI。论文估计货币政策冲击可解释部分相对就业下降，并发现更早趋势。这使结论从“AI 已造成 12% 岗位损失”修正为：AI 与既有远程化和技能升级趋势叠加，初级招聘是最值得优先监测的传导口。

2.2 三种职业阶梯结果

路径 A：阶梯缩窄

企业少招新人，让资深员工＋Agent 完成更多工作。短期利润改善，长期出现资深人才供给不足、组织知识断层和监督能力短缺。

路径 B：阶梯重建

企业把新人从重复制作转向模拟、验证、客户观察和例外案例；用 Agent 记录决策理由并快速反馈。训练时间可能缩短，但需要显式课程和导师预算。

路径 C：职业外部化

新人不再通过正式职位学习，而通过自由职业、平台项目、开源作品、竞赛或自带 Agent 的个人项目建立信誉。它扩大进入渠道，也把训练成本和风险从企业转给个人与家庭。

基准判断是三者并存：头部组织更可能重建阶梯，小型企业使用外部化人才，中型企业可能直接缩窄入口。

2.3 为什么“AI 培训”常常无效

只教工具操作不能解决职业能力。有效训练至少包括：任务边界识别、验证来源、判断何时接管、理解业务损失、保护数据、向客户解释、记录授权和承担结果。人社部门推进 AI 通识、应用与安全继续教育 [S65] 证明供给正在形成，但是否提高就业和工资仍需追踪。

真正的指标不是课程人数，而是受训者的就业率、转岗、工资、事故率、晋升和企业采用深度。培训若不连接真实岗位，可能成为求职者之间的新一轮证书竞争。

3. 工资、利润、劳动份额与财富

3.1 同岗工资与跨岗财富可以反向变化

客服、咨询和写作实验中，低经验或低基线表现者往往获得更大生产率提升 [S61][S63][S74]。如果企业与员工分享收益，这会压缩同一岗位内部的产出和工资差距。OECD 对较早 AI 波次的研究也未发现职业间工资不平等上升，并观察到职业内差距下降迹象 [S59]。

但财富取决于谁拥有模型、云、企业、数据、渠道和互补资本。IMF 的模型显示，劳动替代、劳动互补和资本回报可以让工资不平等与财富不平等朝不同方向变化 [S58]。因此即使普通员工能力更接近专家，资本和企业价值仍可能更集中。

3.2 五种收益分配机制

  1. 工资分享： 稀缺、互补且有议价能力的劳动者获得加薪；
  2. 利润吸收： 企业在价格不变时保留成本节省；
  3. 价格传导： 竞争把收益让给消费者；
  4. 产量扩张： 企业用同样人员服务更多客户，新需求吸收劳动；
  5. 工时改善： 收益变为更少加班或更高自主性，而非货币收入。

判断谁赢，必须看行业竞争、需求弹性、工会／合同、人才稀缺、平台抽成和资本所有权。不能从“生产率上升”直接推出“工资上升”，也不能从“劳动时间下降”直接推出“失业”。

3.3 哪些群体更脆弱

  • 新进入劳动力市场、缺乏可展示经验者；
  • 承担大量标准化文书且没有责任签字权的后台劳动者；
  • 依赖平台分发而没有自有客户关系的创作者和商户；
  • 所在企业缺乏数据、资本和培训的中型组织员工；
  • 无法负担订阅、设备、迁移和无薪学习的人；
  • 高暴露文职中的女性群体。ILO 发现最高暴露梯度在女性就业中的占比高于男性，且高收入国家差距更大 [S55][S57]；但这仍是暴露而非失业事实。

3.4 哪些群体可能获得选择权

  • 能以专业责任、客户信任或现场技能补充 Agent 的劳动者；
  • 能把行业知识产品化的小团队；
  • 过去因语言、行政或规模成本无法进入市场的企业和个人；
  • 有条件把节时转为学习、照护或创业的人；
  • 通过 Agent 获得无障碍、翻译和公共服务支持的群体。

“获得能力”与“获得收入”之间仍隔着客户、支付和信誉，因此政策和创业不应只提供工具，还需提供市场入口和可信凭证。

4. 家庭、消费、教育与照护

4.1 家庭怎样吸收职业转型风险

当企业把培训外部化、招聘变慢、收入更项目化时，家庭通过同住、补贴、教育投资、照护分工和延迟迁移吸收风险。家庭资本越高，个人越能：

  • 等待更好的岗位而不立即接受低质量工作；
  • 负担 Agent 工具、设备、课程和专业认证；
  • 做低收入的项目积累作品；
  • 迁移到机会更多或基础设施更强的地区；
  • 承受创业失败和收入波动。

目前缺少直接纵向证据把 Agent 采用与这些家庭行为连接起来，故以上为弱推断。验证需要毕业生 cohort、家庭转移支付、同住、求职时长、消费和婚育的联结数据。

4.2 消费不是简单“失业所以下降”

社会消费受到两股相反力量：生产率和降价增加实际购买力；入口收缩和收入不确定提高预防性储蓄。可复制数字服务、内容和轻量专业服务可能显著降价，而住房、照护、能源、现场服务和可信责任可能更贵。消费篮子的相对价格变化会重塑福利，即使总体 CPI 反应不明显。

Agent 还会改变消费决策本身：搜索、比价、续费和采购可被自动执行。如果消费者 Agent 真正代表用户，它可降低时间成本和被操纵；如果平台或广告商控制目标，它可能扩大价格歧视、隐藏赞助和冲动交易。判断福利需要看最终价格、选择多样性、退货争议和用户可撤销性，而非交易量。

4.3 教育体系的两重挑战

第一重是教学生产率。OECD 报告所引研究显示教师备课可以节时，但只有课程、评估、培训和系统互操作同步改变，节时才可能转化为学习结果 [S80]。第二重是教育目标：当标准知识生产便宜，教育要更多训练问题定义、验证、协作、伦理、现场能力和持续学习。

若学校仍按可被 Agent 轻易完成的作业筛选，学历信号会失真，雇主可能转向现场测评、作品、试用和关系网络。反之，若富裕学校更早提供高质量 Agent、导师和项目，教育差距可能通过工具使用深度而非工具可得性扩大。

4.4 照护不会因数字陪伴自动解决

医疗和养老 Agent 可做提醒、记录、导航、翻译和低风险陪伴，缓解信息与协调成本。但洗浴、移动、情绪关系、危机处理和临床责任仍需人。供给增加可能释放家庭照护者时间，也可能把更多监测和决策任务推给家庭。真正的净收益要计算家庭无偿工时、专业人员负担、服务结果和错误，而非只看对话次数。

5. 地区、城乡与全球劳动分工

5.1 数字能力降低部分地理边界，也创造新的集聚

Agent 可让小城市企业获得翻译、设计、代码、客服和专业分析，理论上降低人才地理集中。但高端收益又依赖算力、能源、数据中心、融资、大学、客户和专业网络，可能向少数城市集聚。结果是“应用能力扩散、基础设施与利润集中”。

美国 AI 行动计划强调数据中心、能源和芯片基础设施 [S90]；中国以工业集群、行业数据联合体和地方场景推进 [S85—S87]。两国都可能形成新的电力、网络和技能节点，但美国更受许可和州际差异影响，中国更受地方投资协调、重复建设和区域产业基础影响。

5.2 城乡差异取决于服务网络，而非模型价格

农村和小城市并非只缺软件，也缺现场设备维护、可靠网络、医疗教育人员、金融与法律服务以及购买能力。低价 Agent 能补信息，不一定补物理服务。最有效的模式可能是数字 Agent＋区域人员／设备网络：远程专家监督、当地人员执行、异常升级。纯线上产品若没有本地责任和交付，容易停留在建议层。

5.3 全球外包会重新分工

标准写作、翻译、客服、数据处理和初级开发的跨境外包面临压力；但数据整理、模型评测、多语言本地化、内容审核、远程异常处理和行业运营可能增长。发展中地区面临“扰动先于红利”：数字化岗位更容易被远程自动化，而基础设施、技能和本地数据不足使生产率收益较慢 [S60]。

中美企业可能把部分离岸任务回收给内部 Agent，同时把新型数据和运营工作外包。净效应取决于任务升级速度、语言模型质量、客户监管和工资差，而非“服务外包全部消失”。

6. 公共服务、社会信任与制度

6.1 公共生产率必须计入权利和申诉

OECD 研究的政府 AI 用例中，多数目标是自动化、简化或定制服务 [S79]。材料预填、资格预审、案件分流和主动提醒可以降低行政成本，尤其帮助不熟悉规则的人。但公共部门的错误分布往往不均：数据记录差、语言少数、非标准家庭或收入不稳定者更易被误判。

公共生产率不能只用“每案分钟数”衡量，至少还要计算：

  • 一次通过率与错误拒绝；
  • 申诉时间和线下补救成本；
  • 不同群体的错误差异；
  • 人工接管可得性；
  • 规则变更与模型更新的可追溯性；
  • 供应商锁定和公共数据控制。

若平均处理速度提高，但申诉和信任损失上升，净社会收益可能为负。

6.2 无人格不会消除责任，反而催生责任基础设施

Agent 不能成为账户所有人、董事、雇员或诉讼当事人 [S1—S16]。公共和商业制度因此更可能发展受限授权、代理身份、日志、撤销、事故归因和责任承接，而不是短期赋予 Agent 完整人格。新制度会围绕“谁设定目标、谁提供数据、谁批准权限、谁监测、谁赔偿”分配责任。

这会出现新的组织角色：Agent 负责人、权限管理员、模型风险委员会、数据受托、事故调查、独立评测与公共申诉专员。它们只有在工作量和责任稳定后才成为职业。

6.3 信任将从“人看起来可靠”转向“过程可验证”

当 Agent 可大规模生成文本、身份图像和交易请求，外观和流畅性不再是可靠信号。社会会更依赖来源证明、组织签名、权限范围、记录连续性和第三方担保。内容标识、数字替身规则、支付凭证和零信任身份都是这一迁移的早期形态 [S15][S17—S22][S29][S30][S84]。

但验证本身也会形成门槛。如果只有大平台能提供可信身份和争议处理，小企业与个人会更加依赖平台；若开放标准和可携带信誉成熟，则可能形成竞争性中介。

7. 灰色产业与社会成本

本节用于识别风险和治理需求，不提供规避监管或实施欺诈的方法。

7.1 灰色市场为什么会扩张

Agent 降低了试错、复制、同时操作和个性化的成本，使既有诈骗、虚假评价、内容操纵、身份冒充和流量套利更可规模化。记忆和工具权限还扩大了损失半径：一次身份或记忆污染可持续影响后续行动 [S27]。美国监管已通报生成式 AI 伪造身份材料的风险 [S28]；中国治理行动把 AI 冒充、诈骗、网络水军和财经误导列为重点 [S67]。

7.2 新灰产类型

  • 代表虚假消费者或商户制造交易／评价；
  • 操纵供机器读取的商品、简历、网页和知识库；
  • 租借或盗用实名账户、支付权限和企业工具；
  • 伪造来源、证据、人物声音和组织指令；
  • 用低成本 Agent 进行大规模投诉、诉讼威胁或行政资源消耗；
  • 污染长期记忆、评测集和供应链数据；
  • 冒充“独立 Agent”掩盖实际控制者和利益冲突。

这些活动大多不是全新犯罪，而是旧行为在速度、规模、个性化和归责难度上的变化。

7.3 灰产会创造哪些合法需求

合法职业和企业会围绕来源证明、行为异常检测、权限隔离、账户恢复、证据保全、争议调查、记忆完整性、数字替身授权和平台透明形成。最高检研究已指出深度伪造对电子数据和视听证据审查的挑战 [S68]。灰产规模越大，社会为验证支付的“信任税”越高；这会抵消 Agent 的部分生产率收益。

8.1 美国更可能出现的社会现象

  • 白领初级招聘和外包先弱于总就业；
  • 精品专业服务和 AI-native 小团队增加，同时大平台吸收上游利润；
  • 职业许可、保险与诉讼决定医疗、法律和公共服务的自动化边界；
  • 州际监管和公共采购差异造成地区分化；
  • 企业内部工具普及快，但失业保险、医疗保险和培训转换的制度摩擦影响个人承压。

8.2 中国更可能出现的社会现象

  • 制造、政务、教育和基层服务以示范、园区和公共采购方式推进；
  • 大量“AI 应用”项目与真实流程收益之间出现筛选，行业集成和运营岗位增加；
  • 工业办公室任务与现场设备技能出现错配，一边减少后台人员，一边短缺设备／数据／安全人才；
  • 平台生态内的消费者与商户 Agent 更快闭环，但可携带性和平台依赖成为分配问题；
  • 培训与新职业认证扩张，效果取决于是否连接实际岗位而非只增加证书。

这些都是条件式预测，不是已确认事实。需要公开业务职能采用、招聘 cohort、工资、外包、平台抽成和项目绩效数据验证。

9. 三种社会情景

基准：双轨转型

高数据、高工资、知识密集和平台／制造龙头先重组；多数企业停留在增强。初级招聘、外包和岗位内容变化先于总就业，家庭承担部分过渡成本。公共制度逐步增加授权、评测和申诉。

触发： 企业流程集成稳步上升，但高后果行业人工接管保持；需求扩张有限。
证伪： 若 2028 年前初级招聘、外包、管理跨度和培训都无变化，社会影响应下调。

上行：能力普惠与需求扩张

小企业和公共服务获得低成本能力，新产品、医疗教育可及性和地区服务明显扩张；职业阶梯通过模拟、学徒和新认证重建，劳动者分享部分收益。

触发： 中小企业核心流程采用上升、价格下降伴随服务量增长、培训连接真实岗位、开放标准降低平台锁定。
证伪： 若利润只集中在上游、公共错误和数字鸿沟扩大，则退出上行情景。

下行：入口收缩与信任税上升

企业用 Agent 压缩招聘和外包，但新需求不足；青年与中型企业承压。灰产和质量事故推高验证、保险与诉讼成本，公共服务自动化加剧申诉和不信任。

触发： 初级招聘长期低迷、工资与利润脱钩、上游价格／集中度上升、事故与争议显著增加。
证伪： 若真实工资、青年就业、企业进入和公共服务结果同步改善，则下行情景降权。

10. 关键监测指标

  1. 22—29 岁按行业和职业的招聘、就业、工资与离职，而非只看总体青年失业；
  2. 企业初级／资深岗位比、实习转正、导师时数和内部晋升；
  3. AI 使用者的工时、加班、服务量、质量、工资和晋升是否同步变化；
  4. 外包支出、自由职业订单、平台项目价格与任务类型；
  5. 工资份额、利润率、资本收益与企业股权集中；
  6. 家庭对成年子女的转移支付、同住、求职期、教育与订阅支出；
  7. 地区算力、电力、数据中心、机器人、专业人才与企业进入；
  8. 教育中作品／现场测评、AI 使用差异、学习结果与教师负担；
  9. 公共服务处理时间、错误拒绝、申诉、线下补救和群体差异；
  10. 身份冒充、深伪、虚假评价、Agent 交易争议和恢复成本。

11. 最终判断与未知

已确认事实

  • AI 暴露集中于文职及部分高度数字化专业任务，但暴露不能预测失业 [S55][S56]；
  • 企业人数下降仍少见，使用以增强为主 [S34][S71]；
  • 美国高暴露行业的初级招聘与就业出现相对下降信号，但存在重要竞争解释 [S72]；
  • 低经验人员在若干任务实验中即时收益更大 [S61][S63][S74]；
  • 政府、教育和医疗采用面临透明、责任、数据、培训和互操作约束 [S79—S81]。

较强推断

  • 职业入口、空缺补充、外包和岗位内容将先于大规模存量裁员变化；
  • 判断、关系、现场、责任和异常处理的相对价值上升；
  • 同岗技能差距可能缩小，但职业进入和财富差距可能扩大；
  • 公共服务的可申诉性将成为采用上限，而非附属合规功能。

弱推断

  • 家庭资本对等待、迁移、训练和创业的作用会增强；
  • 中型企业员工和低差异化后台劳动者承受更集中压力；
  • 数字能力向地区扩散，但利润、基础设施和高端岗位向少数节点集中；
  • AI 灰产提高全社会验证与信任成本。

未知

  • 初级招聘下降中 AI 的独立因果份额；
  • 新产品和需求创造能否补足被替代任务；
  • 企业是否会重建职业阶梯，还是把训练成本永久外部化；
  • 工资、劳动份额、家庭行为和地区差距的长期方向；
  • 中美 Agent 专门就业、工资和公共服务结果的可比数据。

第二卷的核心不是个人如何“战胜 AI”，而是社会如何避免把企业内部的局部效率，转换成职业入口、家庭资本和公共信任上的长期成本。真正需要监测的是谁获得训练、谁承担错误、谁拥有互补资产、谁能申诉，以及哪些节省最终变成了更低价格、更好服务、更多收入或更少工时。

资料为公开研究整理，不构成证券、法律、职业或个性化财务建议。
