# 第一页：House View

## 核心判断

**拥有预算、任务和记忆但无法律人格的 AI Agent，首先是一种“可行动的软件资本”，而不是新的法律主体。** 它把搜索、起草、协调和部分执行的边际成本压低，却不能自动接管合同责任、物理交付、客户信任与损失承担。因此，2026—2030 年最常见的经济形态不会是“无人企业普遍取代有人企业”，而是：

> 个人任务加速先发生，完整流程收益后发生；招聘和外包先调整，存量岗位后调整；上游基础设施更集中，下游应用和微型企业更碎片化；企业之间的差距更多来自流程、数据和责任重写，而不只是模型访问。

这意味着真实经济冲击的中心不是模型能做多少题，而是企业能否把模型嵌入收入、成本、交付和责任链。美国企业调查已经同时出现“使用很广”和“影响很浅”：一项四国高管调查中 69% 企业报告某种 AI 使用，但约九成报告过去三年对就业或生产率没有影响 [S71]；美国 Census 更严格的企业职能口径下，2025 年末至 2026 年初只有 18% 企业使用，57% 的采用者进入不超过三个职能，66% 只增强任务，就业下降只出现在约 2% 企业 [S34]。这组差异不是统计矛盾，而是本报告的出发点：**“采用”至少有五层，不能用一个百分比代表。**

## 五项主要结论

1. **宏观生产率的主要不确定性在扩散与组织互补，而非单项任务上限。** 任务实验可出现 14%—40% 以上的局部改善 [S61][S74]，但软件研究中 commits 的增幅到实际 releases 大幅衰减 [S73]。宏观模型由此给出从温和到很高的宽区间 [S69][S70]；报告不把高端值当作基准。
2. **就业冲击更可能先穿过招聘、外包和工时，而不是裁员。** 企业层就业下降仍少见 [S34][S71]，但美国行政数据发现最暴露行业的早期职业招聘在 ChatGPT 后相对下降约 9% [S72]。这能与“总就业暂未大降”同时成立。
3. **企业规模结果不是“大企业必胜”，而是三层分化。** 大企业在数据、资本、合规和系统集成上领先；小团队通过通用模型获得专业能力；中型、低差异化、既无上游议价又有组织成本的企业最易受压。OECD 的大中小企业采用差距 [S76] 与中小企业使用后外包依赖下降 [S75] 同时支持这一判断。
4. **产业集中将分层发生。** 芯片、云、模型与身份／分发层存在集中、纵向整合和转换成本风险 [S82][S83]；但低边际成本也会催生大量细分应用和微型企业。更可能的结构是“上游寡头化、下游碎片化、中间层挤压”，不是全经济单向垄断。
5. **中美不会走同一路径。** 美国更可能由云／模型企业、风险资本、专业服务和联邦采购推动，先冲击知识服务与软件；中国更可能由完整制造链、机器人、地方场景、国企／公共采购和行业数据工程推动，把 Agent 更快接到实体设备和供应链。两国都受数据、能源、责任和技能约束，但约束的排序不同。

## 置信度、情景与改变观点的条件

- **总体置信度：中等。** 企业采用、任务效果和政策方向已有较好证据；Agent 专门的财务、价格、进入退出和集中度数据仍不足。
- **基准情景（研究判断约 55%）：** 2026—2030 年从任务助手转向若干标准流程，企业主要通过少招、少外包、增加产出和压缩周转时间吸收收益；到 2031—2035 年，软件、专业服务、零售入口与部分制造协调发生企业级重组。
- **上行情景（约 25%）：** 可靠性、工具权限和流程互操作快速改善，需求因降价与新产品明显扩张；生产率收益超过成本替代，微型企业和新服务大量出现。
- **下行情景（约 20%）：** 质量事故、法律责任、能源／算力、数据孤岛和组织阻力使使用停留在个人工具；上游资本开支很高、下游财务收益很低，出现投资去泡沫和集中加剧。

以上概率只用于表示相对判断，不是统计预测。若 2028 年前出现以下证据，本报告会改变观点：采用企业的流程覆盖率和财务收益不再提高；人工接管与事故长期高位；企业初级招聘、管理跨度、外包率、单位价格和产品数量没有可辨变化；或相反，Agent 已在多个行业形成经审计的端到端收入与显著净新增需求。

# 1. 范围、定义与分析方法

## 1.1 本报告研究的不是所有 AI

这里的 Agent 至少具备四项能力：接受持续目标、在权限内调用工具、维护跨步骤状态或记忆、发起对外行动。聊天、摘要或单次代码补全只证明某类任务能力，不证明企业已把行动权交给系统。Agent 没有法律人格，意味着账户、资产、合同、雇佣和诉讼地位仍挂在人或组织名下 [S1—S16]。因此技术上的“自主”与经济法律上的“独立”必须分开。

> **红队后的证据校准：** 当前强实证主要研究生成式 AI 助手、宽口径企业 AI 或任务暴露，而不是完整的“有预算、有记忆、可调用工具”的 Agent。报告使用这些证据来约束任务入口、互补条件和潜在瓶颈；凡涉及端到端流程、企业边界、产业结构和长期社会结果，均是条件式推断，不是对已发生 Agent 经济的直接测量。参见 [`23_real_economy_red_team.md`](23_real_economy_red_team.md)。

## 1.2 采用率被拆成五层

| 层级 | 可观察问题 | 典型假阳性 |
|---|---|---|
| 接触 | 员工是否试用过工具？ | 个人账号偶尔写邮件 |
| 使用 | 企业是否在任一职能使用？ | 单部门、低频、无正式流程 |
| 集成 | 是否接入数据和业务系统？ | 仍靠人工复制粘贴 |
| 流程 | 是否端到端执行并只处理例外？ | 成功案例无法覆盖长尾 |
| 财务 | 是否改变收入、成本、价格、资本和人员？ | 节省时间但没有释放预算或增加产出 |

美国 Census 的约 18% 与四国高管调查的 69% 分别更接近第二层的严格与宽松口径 [S34][S71]；OECD 对 G7 核心业务职能的 1.9%—6.1% 更接近第三、四层 [S76]。因此报告不进行简单国家排名，也不把采用等同于生产率。

## 1.3 从事实到结论的可复核链条

每个核心判断均按以下链条展开：

> 技术能力 → 任务成本与质量 → 流程中的弱环节 → 企业收入／成本 → 招聘、投资、外包和定价 → 进入退出与集中度 → 工资、消费、地区和财政 → 监管与组织反应 → 下一轮采用。

证据分为五级：已确认事实、较强推断、弱推断、假设、未知。单项实验只支持对应任务；政策文件只证明目标；厂商产品只证明供给；暴露指数只证明潜在任务相关性。

# 2. 为什么任务收益经常没有变成企业收益

## 2.1 “弱环节”而非平均能力决定交付

软件开发是最清楚的例子。Agent 显著提高代码活动，但实际发布增幅远小于 commits [S73]。原因是最终产品由需求、代码、审查、安全、测试、部署、营销和客户采用串联组成。若 Agent 只把其中一环加速 3 倍，而其余环节不变，总交付不会增加 3 倍。

可以把完整流程的单位成本写成：

> 总成本 = Agent 可处理任务成本 + 人工复核与例外成本 + 集成固定成本 + 错误／责任预期损失 + 算力与供应商成本。

很多演示只测第一项；企业财务要同时计算后四项。如果个人节省两小时，却没有减少加班、增加服务量、缩短周转或减少外包，财务收益接近零。66 家企业的随机实验发现实际使用者每周邮件少约两小时，但未检测到任务数量或构成变化 [S62]，正说明时间节省需要组织重新配置才能聚合。

## 2.2 收益为何先流向质量和产量，而非裁员

企业面对不确定技术通常不会立刻删除岗位，因为重新招聘、客户关系、隐性知识和事故成本都很高。更低风险的吸收顺序是：

1. 减少积压和加班；
2. 提高质量或缩短交付；
3. 增加同一团队的客户和产品数量；
4. 减少外包、临时工和空缺补充；
5. 重新定义岗位；
6. 在需求没有扩张时才进行存量裁员。

Census 中就业下降企业很少 [S34]，但早期职业招聘相对下降 [S72]，恰好符合第 4 步先发生。它也解释为什么员工可以感觉就业入口变差，而宏观失业率和企业总人数尚未出现同等幅度变化。

## 2.3 能力边界不平滑，监督本身成为生产要素

咨询实验的结果不是“AI 对知识工作提高 40%”这一句，而是两部分：在能力边界内更快更好；边界外更容易因过度依赖而答错 [S74]。因此企业价值取决于能否事先分类任务、实时识别异常、把高后果决定升级给人。监督不是临时补丁，而是新的生产函数组成。它会催生评测、证据核验、权限工程、异常接管和责任接口岗位。

# 3. 宏观结果：增长、价格、投资、需求与劳动份额

## 3.1 生产率：为何合理估计区间很宽

Acemoglu 的任务模型把宏观收益约化为“受影响任务份额 × 平均任务成本节省”，给出十年累计 TFP 不超过 0.66% 的温和估计，并警告早期实验偏向容易学习、容易度量的任务 [S69]。OECD 在不同采用和暴露参数下，给高暴露 G7 经济体每年劳动生产率增长贡献 0.4—1.3 个百分点的宽区间 [S70]。

二者不能简单取平均，因为差异来自四个假设：

- 什么任务在十年内真正可用，而非理论暴露；
- 企业采用速度和使用强度；
- 单项任务收益能否穿过弱环节；
- 是否计入新产品、科研创新和产业重配。

本报告的基准判断更接近“前期温和、行业高度分化、后期取决于组织重写”。这是较强推断，不给单点 GDP 预测。理由是截至 2026 年，真实企业使用范围仍浅 [S34][S71]，而核心业务采用低于宽口径使用 [S76]。

## 3.2 价格与需求：成本下降不必然增加 GDP

单位成本下降有四种去向：价格下降、利润上升、工资／工时改善、产量与新品增加。宏观结果取决于需求弹性：

- 软件、内容和部分专业服务的供给可快速扩张，价格下降可能催生大量过去买不起的需求；
- 医疗、教育和养老受支付预算、资格和专业供给约束，节省可能变成更多服务，也可能只变成更大行政量；
- 制造、建筑和农业还受设备、材料、土地和能源约束，认知成本下降只占总成本的一部分；
- 零售若只提高广告和价格歧视能力，生产率收益可能主要转为平台租金，而非消费者福利。

因此“AI 导致通缩”不是稳健总量结论。更可能先出现相对价格变化：可复制知识服务和标准内容变便宜，可信责任、现场服务、算力能源、独特数据和人类关系溢价上升。

## 3.3 投资：无形资产与物理基础设施同时增加

Agent 不是纯软件替代。企业需要购买云、模型、数据治理、系统连接、安全、评测与培训；制造和现场行业还需传感器、机器人和设备。美国政策把数据中心、芯片和能源建设列为核心 [S90]；中国政策把行业数据、制造场景、普惠算力和公共应用并行推进 [S85—S87]。这会产生两阶段投资：先是上游基础设施高资本开支，后是企业流程和设备改造。

若下游财务收益迟迟不出现，高资本开支会面临回报压力；若收益出现，算力、电力、网络、安全、设备集成和技能供给可能成为新瓶颈。宏观上，这更像一次资本结构调整，而不是无成本的软件升级。

## 3.4 劳动份额与分配：取决于谁拥有互补资产

如果 Agent 替代部分工时，而模型、云、数据和渠道由少数企业拥有，初期收益更可能进入利润和资本回报；如果劳动者掌握客户、专业责任、现场执行或稀缺判断，AI 可提高其边际产出和工资。客服与咨询实验中较低经验者收益更高 [S61][S74]，可能压缩技能差距；但企业若因此减少初级招聘，长期又会削弱经验形成并扩大家庭背景差距 [S72]。这两条机制并不冲突：**同一岗位内的生产率差距可能缩小，进入该岗位的机会却可能减少。**

# 4. 企业会如何变化：成本、产品、层级与边界

## 4.1 管理跨度扩大，但中层不会机械消失

Agent 可整理信息、追踪任务、生成汇报和提醒异常，使管理者监督更多流程。但中层还承担冲突协调、人才培养、隐性目标翻译和责任承接。若企业只是自动生成更多报表，管理负担反而会上升。真正的层级压缩需要三个条件：指标可验证、例外可分类、决策权限可撤回。

因此可观察顺序可能是：行政协调岗位减少 → 一线负责人管理跨度扩大 → 跨职能小团队增加 → 责任和质量岗位上升。若只看职位名称，会错过工作内容变化。

## 4.2 自制与外包边界重新画

通用 Agent 降低企业内部完成翻译、设计、客服、分析、招聘和轻量开发的固定成本。OECD 中小企业调查已发现使用者报告对外部承包商依赖下降，而总体人员需求变化有限 [S75]。这支持“外包回流先于裁员”。

但另一方向也存在：高度专业的 Agent 运营、数据清洗、安全审计和现场接管需要规模经济，企业可能把这些新职能外包给平台。结果不是外包总量单向下降，而是旧外包（低差异化知识生产）收缩，新外包（基础设施、责任和行业数据）增长。

## 4.3 产品边界扩张，企业可能从卖工具转向卖结果

当 Agent 能持续执行，软件和服务不再只提供界面或建议，而可能交付“完成采购”“追回应收”“维护设备”“让申请通过合规预审”等结果。按席位订阅会受到按任务、按结果或风险共担定价的挑战。无人格使供应商不能把失败责任推给 Agent，反而要求更清楚的服务等级、授权、日志和赔偿。

这种转型的难点是结果归因：销售增长可能来自市场，而非 Agent；事故可能来自错误数据，而非模型。因而合同、评测和保险会成为新产品的一部分。

# 5. 大企业、小企业与市场集中

## 5.1 为什么大企业先用得深

美国 Census 显示大型企业采用率明显更高，部分知识密集行业超大型企业达到 50%—60% [S34][S35]。OECD 跨国数据也显示大企业约 40%，10—49 人企业约 11.9% [S76]。原因不是管理者更“懂 AI”，而是大企业拥有：

- 可供模型调用的历史数据和标准流程；
- 安全、法务、采购和内控团队；
- 能承担集成固定成本的预算；
- 更大任务量，使一次集成可摊销；
- 客户、品牌和渠道，能把生产率转为收入。

这些互补资产意味着能力相同，财务回报不同。

## 5.2 为什么小团队也可能赢

生成式工具降低文字、代码、设计、客服和分析的边际成本。OECD 调查中 31% 的中小企业使用生成式 AI，并报告技能补缺和新产品收益 [S75]。小团队没有遗留系统和层级，可从第一天围绕 Agent 设计流程，决策快、细分客户理解深。它们可以把过去需要十几人的后台缩成几人，进入以前最低有效规模过高的市场。

但“能生产”不等于“能获客、负责和融资”。品牌、分发、支付、保险和监管仍是门槛。因此小企业优势最大的是低后果、细分、快速试错、客户关系密集的领域，而非所有行业。

## 5.3 中型企业为何可能最受压

中型企业既承担正式组织、销售、合规和人员成本，又可能没有规模数据、平台地位和资本；其标准化产品还容易被小团队低价复制。此判断目前是弱推断，关键验证指标是中型企业的毛利、进入退出、并购和员工规模分布，而不是新闻中的个案。

## 5.4 集中为何必须按层观察

FTC 和 OECD 已识别云商—模型开发者合作、云支出承诺、转换成本、敏感信息访问和关键输入集中 [S82][S83]。这支持上游集中风险。但下游存在相反力量：同一模型可以服务许多细分企业，降低应用开发固定成本。

所以至少要分别监测：芯片、云、基础模型、Agent 运行时、企业软件、行业应用、分发／支付、最终产品八层。某一层集中上升不等于全链垄断；真正危险的是纵向捆绑使上游力量跨层传导并封锁数据、客户和切换。

# 6. 八行业的差异化路径

详细行业机制见第二十号矩阵。这里给出主结论：

1. **软件与互联网：** 最快从任务优化走向流程替代，但发布、质量、获客和运维使收益衰减；上游集中、下游产品爆炸。
2. **专业服务：** 最先动摇初级劳动与工时收费；责任、品牌和客户关系决定头部机构与精品团队并存。
3. **零售与平台：** 关键不在生成商品描述，而在消费者 Agent 是否改变搜索和渠道入口；平台既可能巩固，也可能被跨平台采购层削弱。
4. **制造与物流：** 计划、质检、维护和供应链先优化；只有与设备、机器人和主数据闭环，才会改变工厂和产业边界。
5. **医疗、教育与养老：** 文书和排程高暴露，专业责任与面对面服务低可替代；更可能重构服务编排而非消灭专业主体。
6. **内容与文化：** 生产趋于充裕，注意力、可信身份、IP、授权和社群变稀缺；生产碎片化、分发集中。
7. **农业、建筑与现场：** 认知控制层先变，物理执行依赖机器人、传感器和本地服务；区域性不会快速消失。
8. **公共部门：** 高量低风险服务先自动化，公平、申诉和法定程序决定上限；效率与信任必须共同计算。

这八类不是行业命运，而是瓶颈排序。相同模型进入不同行业，会因工资、物理资本、许可、责任、需求和数据而得到完全不同结果。

# 7. 中国与美国：同变量比较，而非国家标签

| 维度 | 美国 | 中国 | 当前含义 | 不能推出什么 |
|---|---|---|---|---|
| 产业结构 | 知识密集服务、软件、云与资本市场强 | 制造链、工业集群、平台消费和公共场景强 | 美国先显现知识工作重组，中国更可能把 Agent 接入制造与公共场景 | 不能据此断言一国总生产率必然更高 |
| 企业采用数据 | Census 可按规模、行业、职能和任务观察；2025—26 约 18% 严格口径 [S34] | 2023 年 148.2 万家规模以上企业宽口径 AI 使用 16.4% [S88] | 美国更易跟踪使用深度；中国可观察规模企业数字化基础 | 两数不能直接比较排名 |
| 物理自动化 | 2024 年工业机器人存量约 39.37 万台 | 超过 200 万台 [S78] | 中国具有更多数字—物理结合场景，美国存在自动化追赶需求 | 台数不等于利用率或生产率 |
| 扩散机制 | 云／模型企业、风险资本、企业采购、联邦与州政策 | 中央目标、地方试点、国企／公共采购、行业联合体 | 美国更市场分散，中国更可做场景工程 | 政策目标不等于落地效果 |
| 上游约束 | 芯片设计、云和模型优势，但能源、许可和集中风险突出 [S82][S83][S90] | 制造与应用生态强，先进算力获取、地方重复建设和数据协同是约束 | 两国基础设施瓶颈类型不同 | 不能只按模型排行榜判断产业结果 |
| 劳动成本与保护 | 高工资提高自动化回报，州法、职业许可、诉讼和合同差异大 | 服务业人工成本相对低，劳动调整、平台用工和地区政策不同 | 美国知识服务替代激励更强；中国实体应用可能靠规模和政策 | 不能把国家平均替代行业工资和制度 |
| 中小企业 | 通用 SaaS、云生态和专业服务市场成熟，但采用差距大 | 工业集群、平台生态和政策补贴可共用基础设施 | 两国都可能出现小企业赋能与平台依赖并存 | 政策扶持不能证明中小企业最终受益 |
| 数据与责任 | 行业法、州法、合同和诉讼多层治理 | 个人信息、平台责任、实名、行业监管和行政推进 | 美国合规碎片化，中国部署集中但责任可能更前置 | 不能简化为“美国放任／中国管制” |

## 7.1 美国的基准路径

2026—2030 年，软件、专业服务、企业后台和营销继续领先；大型企业因系统集成扩大差距，小团队大量涌现。早期职业招聘和外包先受影响。算力、能源和数据中心资本开支扩大，同时监管关注上游集中、公共采购锁定和高影响决策。若需求扩张不足，中型软件、BPO 和标准专业服务利润率承压。

## 7.2 中国的基准路径

2026—2030 年，“人工智能+”通过制造、消费、民生和治理场景推进 [S85]；工业数据联合体和普惠算力试图降低制造中小企业门槛 [S86][S87]。更容易形成行业解决方案、机器人／设备编排和公共服务试点，但项目制、地方重复建设、价格竞争和“部署多、使用浅”可能压低软件利润。真正的分水岭是场景是否从示范转为持续财务与生产指标。

## 7.3 不会机械重复的部分

美国知识工作实验不能直接外推到中国制造业；中国机器人存量不能直接外推为自主 Agent；美国上游集中不等于所有应用垄断；中国集中推进也不等于采用更深。可比的是机制：互补资产、固定成本、责任、需求和组织重写，而不是相似的采用数字。

# 8. 三阶段演化

## 阶段一：工具扩散与影子使用

员工试用，企业制定政策，收益集中于写作、代码、客服和营销。采用数字上升，但财务影响不清。当前大部分企业仍在此阶段 [S34][S71]。

## 阶段二：流程重写与责任工程

企业选择高量、标准、可复核流程，接入数据和工具，设定预算、权限、日志和异常升级。招聘、外包、管理跨度和服务水平开始变化。此阶段的瓶颈不再是模型，而是组织、数据、责任与切换成本。

## 阶段三：企业边界与产业结构变化

当多流程贯通且结果可合同化，企业从卖工具转为卖结果，微型企业进入、部分中型企业退出或并购，上游平台试图垂直整合。新产品和需求扩张决定这是生产率繁荣还是利润再分配。

分期按机制变化，不按年份硬切。不同企业和行业可同时处于不同阶段。

# 9. 机会方向与客户

本节回答创业机会，但不把报告变成创业清单。最有支付意愿的需求来自“个人工具已有、企业结果未出现”的断层。

| 机会 | 首要客户 | 为什么现在形成 | 形成规模的必要条件 |
|---|---|---|---|
| 流程发现、基线与 ROI 证明 | 业务负责人、CIO、运营与财务 | 企业不能用调用量证明收益 | 能连接周期、质量、收入、外包和人员指标 |
| Agent 权限、身份、预算和撤销 | 金融以外的采购、软件、平台、公共部门、高风险行业 | Agent 无人格，行动仍需归属于组织 [S1—S16] | 与现有 IAM、ERP、支付、合同和审计集成 |
| 异常接管与可观测性 | 医疗、制造、物流、政府、企业软件 | 边界外错误决定能否进入生产 [S74] | 低延迟、可回滚、责任清晰 |
| 行业数据与语义层 | 制造、供应链、医疗、公共服务 | 通用模型不理解碎片化企业状态 [S77][S86] | 数据权利、标准和多系统连接可复用 |
| 中小企业托管 Agent | 商户、小厂、专业服务 | 工具门槛下降但组织与技能不足 [S75][S76] | 人工兜底、垂直模板、低获客成本 |
| 机器可读交易与信誉 | 零售、采购、平台、品牌 | 消费与企业 Agent 需要可信库存、条款、评价和身份 | 接口开放、支付授权和争议处理成熟 |
| 人机岗位与训练管道 | 大企业、人力资源、学校、政府 | 初级任务与招聘入口可能同步减少 [S72] | 培训与真实岗位、晋升和认证绑定 |
| 现场服务网络 | 制造、农业、建筑、物流 | 纯软件无法处理物理长尾 | 设备接入、保险和区域服务密度 |

最可防御的企业不是拥有“最聪明的 Agent”，而是控制难复制的工作流数据、客户关系、责任接口、现场网络或可验证结果。最大的创业陷阱是把模型演示当产品、把节时当预算、把用户当付款方、把政策目标当市场规模。

# 10. 主要风险与反向机制

1. **生产率悖论延长。** 投资、培训和双轨流程先增加成本，统计生产率多年后才出现。
2. **质量和责任事故。** 低频高损失错误抵消大量日常节省，高后果行业退回人工。
3. **上游租金吞噬下游收益。** 云、模型和分发涨价，使企业没有净利润改善。
4. **需求不足。** 供给增加而客户预算不变，价格战与低质泛滥先于消费扩张。
5. **人才管道断裂。** 初级工作减少，使未来资深人才和监督能力不足，反过来限制 Agent 扩散。
6. **中小企业数字鸿沟。** 轻量工具普及，但核心流程集成、数据和安全差距扩大。
7. **公共信任下降。** 公共服务或医疗错误缺乏申诉，效率收益转为政治和补救成本。
8. **能源与地区约束。** 算力投资集中到具备电力、网络和许可的地区，加剧地区差距。
9. **灰色产业扩张。** 身份冒充、虚假评价、内容污染和接口操纵降低信任，增加验证成本 [S27][S28][S67][S68]。

# 11. 关键监测指标

| 层级 | 指标 | 为什么比“用户数”更重要 |
|---|---|---|
| 任务 | 人工接管率、错误和返工、单位任务成本 | 判断演示能否进入生产 |
| 流程 | 覆盖职能数、端到端完成率、异常升级 | 判断使用深度 |
| 企业财务 | 收入／员工、毛利、研发与销售费用率、外包支出 | 判断节时是否转成财务结果 |
| 劳动 | 初级招聘、空缺补充、工时、转岗、晋升和培训 | 识别先于裁员的调整 |
| 产品与需求 | 新品数、价格、服务量、客户留存和支付意愿 | 区分成本替代与市场扩张 |
| 企业边界 | 管理跨度、部门数、自制／外包、供应商数量 | 判断企业重组 |
| 产业组织 | 企业进入退出、规模分布、并购、集中度 | 判断产业重构 |
| 上游依赖 | 云／模型份额、切换成本、多云／开源使用 | 判断租金和锁定 |
| 物理转化 | 机器人／设备利用率、良率、停机、库存与交期 | 判断制造和现场价值 |
| 社会与公共 | 青年就业、工资与劳动份额、申诉／错误群体差异 | 判断收益分配与信任 |

# 12. 最终判断：事实、推断、假设与未知

## 已确认事实

- 企业 AI 使用扩大，但问卷口径导致 18% 与 69% 等巨大差异；严格业务流程集成远低于轻量使用 [S34][S71][S76]。
- 大企业与知识密集行业采用更深；多数采用企业仍集中于少数职能，以任务增强为主 [S34][S35]。
- 特定任务可出现显著速度和质量收益，但完整交付端的收益会被弱环节稀释 [S61][S73][S74]。
- 企业总就业的可见下降仍少见，但美国早期职业招聘在高暴露行业出现相对收缩证据 [S72]。
- AI 基础设施具有集中、纵向整合和转换成本风险 [S82][S83]。

## 较强推断

- 2026—2030 年企业调整主要通过少招、减少外包、增加产量、提高质量和改变岗位内容发生，而非立即大裁员。
- 企业差距主要由数据、流程、客户、责任和物理互补资产决定；模型访问会越来越像必要但不充分条件。
- 软件、专业服务、内容和企业后台先重组；制造和现场行业需要更长的设备与数据整合期。

## 弱推断

- 中型通用软件、低差异化专业服务和旧式知识外包最可能被两端挤压。
- 上游集中、下游碎片化可能成为主导产业形态，但垂直捆绑或开放标准都可能改变方向。
- 中国可能比美国更早出现大规模工业和公共场景 Agent，美国可能更早出现高利润全球化知识服务 Agent。

## 假设

- Agent 的工具调用、记忆与可靠性继续改善，且授权和责任机制没有完全阻断部署。
- 企业能够获得足够算力、能源、数据和人才进行流程重写。
- 需求会对部分降价和新产品作出正向反应。

## 未知

- Agent 对企业利润、价格、生产率、并购和净就业的独立因果效应；
- 新需求和新任务能否抵消流程替代；
- 中国小微企业采用深度、美国企业实际 Agent 而非广义 AI 使用；
- 市场集中究竟停留在上游，还是通过身份、支付、分发和数据扩散到最终行业；
- 2030 年以后，物理机器人与数字 Agent 的结合速度。

第一卷的结论不是“AI Agent 必然重构所有行业”，而是给出一条可检验的升级路径：**任务收益只有穿过流程、责任、需求和组织四个转换器，才会成为企业收益；企业收益只有改变招聘、投资、定价和进入退出，才会成为宏观与社会变化。**
