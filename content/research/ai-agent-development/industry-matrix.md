# 第二十号文件：AI Agent 行业转型矩阵

日期：2026-08-05  
证据索引：文中的 `[Sxx]` 对应 [`02_source_log.md`](02_source_log.md) 的来源编号。

## 一、怎样读这张矩阵

本文件不是给行业贴“会被替代／不会被替代”的标签，而是判断变化能够走到哪一层：

| 层级 | 判断问题 | 关键指标 |
|---|---|---|
| 局部优化 | 某个任务是否更快、更便宜或更稳定？ | 单位时间、错误率、返工率、质量分布 |
| 流程替代 | 一段端到端流程能否主要由 Agent 完成？ | 人工接管率、异常率、每单人工分钟数 |
| 企业重组 | 部门、层级、外包和自制边界是否改变？ | 初级岗位、管理跨度、外包率、固定成本 |
| 产业重构 | 利润池、进入壁垒、企业规模和产品类别是否改变？ | 价格、毛利、进入退出、集中度、并购、新收入 |

从一层升级到下一层，至少要跨过四道门：任务可数字化、流程可重写、责任可配置、需求或产品空间足够大。任何一门长期不通，行业就可能停留在增强而非替代。当前美国 Census 数据显示，企业使用已扩散，但多数采用者只进入不超过三个职能，且 66% 只报告任务增强；发生就业下降的企业约 2% [S34]。这构成全矩阵的现实基线。

## 二、八行业总表

| 行业 | 2026 前主要形态 | 最可能的第一阶段 | 升级为企业重组的条件 | 升级为产业重构的条件 | 最可能的市场结构 |
|---|---|---|---|---|---|
| 软件与互联网 | 数字任务、模块化生产、云平台集中 | 编码、测试、运维和客服优化 | Agent 贯穿需求—代码—测试—发布，且质量责任可控 | 软件单位成本大降并催生大量小众产品；模型、云、分发权重排 | 上游集中，下游产品爆炸，中型通用软件受压 |
| 专业与商业服务 | 以工时、资历和信任收费 | 研究、起草、分析、交付物生产 | 初级人员减少，合伙人管理更多 Agent／项目 | 计时收费转向结果收费，专业责任与品牌成为核心壁垒 | 头部信任集中与精品小团队并存 |
| 零售、电商、本地生活与平台 | 流量、库存、履约、商户与平台撮合 | 搜索、营销、客服、补货和定价辅助 | 消费 Agent 与商家 Agent 直接协商并接入库存履约 | 入口由“页面与广告”转为“被 Agent 选择”，渠道租金重分配 | 平台可能巩固，也可能被跨平台采购层削弱 |
| 制造、供应链与物流 | 物理资产重、质量与停机代价高 | 计划、质检、维护、采购和路线优化 | 与 MES/ERP/机器人形成闭环，现场异常可安全接管 | 柔性生产使小批量定制成本下降，供应网络边界改变 | 龙头扩大数据与资本优势，专业集成商和柔性小厂获得窗口 |
| 医疗、教育与养老 | 强许可、强责任、人与人服务 | 文书、排班、备课、随访和行政辅助 | 专业人员成为少量高风险决策者，常规流程由 Agent 编排 | 服务单位从机构转为持续数字陪伴＋线下节点 | 高信任机构和平台集中；本地照护供给仍分散 |
| 内容、广告与文化 | 创作供给稀缺、注意力和版权控制利润池 | 素材生成、版本化、翻译和投放优化 | 小团队批量生产，岗位从制作转向策划、编辑和授权 | 内容供给近乎无限，稀缺性转向可信来源、人物权利和分发 | 生产碎片化，注意力与身份授权集中 |
| 农业、建筑与实体现场 | 环境非结构化、物理执行与安全责任强 | 估算、设计、监测、调度和合规文书 | 与传感器、无人机、机器人和设备数据闭环 | 标准化构件、远程运营和服务化设备改变项目组织 | 地区性服务商仍重要；设备、数据平台和总包可能集中 |
| 公共管理与公共服务 | 法定程序、预算采购、问责和公平约束 | 查询、材料预审、案件分流、欺诈检测 | 跨部门数据互通和可申诉的人机流程形成 | 公共服务由被动申请转向主动触达，采购和行政层级重写 | 国家／地方平台集中，执行与专业服务多层外包 |

## 三、行业一：软件与互联网

### 原始结构与 Agent 入口

软件生产几乎全部是数字流程，因此最早出现可见产出增益。Agent 可进入需求拆解、编码、测试、文档、故障定位、迁移、客服和增长运营。10 万余开发者的研究显示，自主编码 Agent 对 commits 的增幅远高于实际 releases：约 180% 对 30% [S73]。这不是“Agent 没用”，而是说明软件交付是串联系统；代码生成加速后，需求判断、安全复核、架构兼容、部署批准和客户采用成为新瓶颈。

### 四类结果的条件

- **局部优化：** Agent 只在 IDE 或工单内给建议，团队结构、发布频率和产品范围不变。
- **流程替代：** 标准化修复、测试生成、依赖升级和低风险内部工具可以由 Agent 完成，人只审核合并。
- **企业重组：** 当一名资深工程师能监督多个 Agent，初级编码和测试岗位减少，产品经理、工程师、运维的边界重新组合；衡量重点应从 commits 转向发布、缺陷、收入和留存。
- **产业重构：** 只有当低成本开发同时降低获客、运维、合规和分发成本，小众软件市场才会扩大。否则“做出来更便宜”只会造成产品过剩和营销成本上升。

### 大小企业与新利润池

大企业拥有代码库、客户、云额度、安全体系和分发入口，能把 Agent 接入完整生命周期；小团队则没有遗留系统，能直接采用 Agent-native 架构。最脆弱的可能不是最小企业，而是依赖通用功能、收取按席位订阅费、又缺乏平台分发权的中型软件商。新利润池将出现在 Agent 运行时、评测、权限、可观测性、企业数据连接、安全发布和按结果收费的软件服务。

### 中美差异、客户与验证

- **美国：** 云、模型和开发者平台优势强，上游合作和转换成本已被竞争监管关注 [S82][S83]；更可能率先出现高毛利基础设施和全球化小团队。
- **中国：** 开源模型、应用工程、产业客户和本地部署重要；价格竞争可能使模型利润更快向行业集成、私有数据和交付服务转移。
- **创业客户：** 软件企业 CTO、平台工程、安全与合规团队、拥有大量遗留系统的非技术企业。
- **证伪：** 若未来两年 releases、缺陷率、研发费用率、产品发布数量和小团队收入没有随 Agent 使用显著改变，则“软件产业重构”应降为开发工具升级。

## 四、行业二：专业与商业服务

### 原始结构与 Agent 入口

咨询、法律、会计、招聘、营销代理、企业研究等行业把专业判断、客户关系、责任和大量初级资料劳动打包出售。BCG 随机实验显示，在模型能力边界内，速度和质量显著提高；边界外任务因过度依赖反而更容易错误 [S74]。因此核心变化不是“报告自动写”，而是金字塔式人才结构是否仍需要大量初级人员来搜索、整理、建模和起草。

### 四类结果的条件

- **局部优化：** 专业人员使用 Agent 起草，但计费、复核和团队配置不变；收益可能被内部返工吸收。
- **流程替代：** 标准尽调、合同初审、候选人筛选、常规税务和市场材料可以形成机器主导流水线，但签字、意见和客户沟通仍由人承担。
- **企业重组：** 当高级人员管理跨度扩大，初级员工既减少又失去“边做边学”的训练任务，合伙制的晋升漏斗需要重建。
- **产业重构：** 若客户可验证结果并接受按结果或持续订阅付费，工时收费会受压；若责任仍高度个人化，品牌和保险反而使头部机构更强。

### 市场结构与新职业

两种方向可同时发生：头部机构因信任、数据和责任承接集中高价值项目；少数专家＋Agent 组成精品团队，抢占中低端与细分市场。传统中型机构若既没有品牌又承担高人工成本，最易受挤压。新职业不是简单“提示词工程师”，而是专业工作流设计者、证据／来源核验员、Agent 输出审计师、专业责任接口经理和机器可读知识产品经理。

### 中美差异、客户与验证

- **美国：** 计时费、高人工成本、诉讼和专业保险同时提高替代激励与责任门槛；小型专业服务可更快产品化。
- **中国：** 人工成本较低、项目制与关系型销售占比高，纯成本替代激励较弱；但平台客户、国企和政府采购可推动标准化交付。
- **创业客户：** 律所、会计师事务所、咨询与招聘机构、企业法务／财务／采购部门。
- **证伪：** 若初级招聘、每项目人员数、计费结构和合伙人管理跨度没有变化，行业仍处个人助手阶段。

## 五、行业三：零售、电商、本地生活与平台

### 原始结构与 Agent 入口

该行业的关键不是商品信息生成，而是流量、信任、库存、履约与售后。美国零售企业 2026 年春的宽口径 AI 使用约 14%，低于全行业均值 [S35]，说明消费者看见的推荐技术不等于零售商内部已深度 Agent 化。Agent 最先优化商品上架、广告素材、客服、需求预测、补货、比价与促销。

### 从优化到重构的链条

1. 商家 Agent 降低上架、投放和客服成本；
2. 消费者 Agent 降低搜索、比较和重复购买成本；
3. 流量入口从页面浏览转为机器代表用户询价、筛选和下单；
4. 商品描述与广告说服力的重要性下降，可验证价格、库存、履约、退换和信誉数据的重要性上升；
5. 若平台控制身份、支付、评价和接口，平台抽成可能上升；若消费者 Agent 可跨平台调用，原平台流量租金可能下降。

因此，Agent 并不天然让平台更强或更弱，决定变量是接口开放、支付授权、商户数据可携带性和争议处理。现有 Agent 支付协议表明受限凭证和意图授权正在形成 [S17—S22]，但真实交易规模和争议率仍未知。

### 企业结果、新产业与灰色空间

小商户可获得大型企业式的多语言客服、选品和营销能力；大型平台则掌握全市场行为数据、支付和履约。可能出现“上游平台集中、商户供给更碎片化”。新行业包括机器可读商品与服务目录、跨平台采购代理、可验证库存／评价、Agent 争议代理和本地商户运营服务。灰色市场会围绕对 Agent 的搜索操纵、虚假评论、接口套利、隐藏赞助和身份／授权盗用扩张，但本报告不提供操作细节。

### 中美差异、客户与验证

- **美国：** 商户技术栈和支付较分散，跨平台 Agent 有较大空间，但州法、消费者保护和平台接口构成摩擦。
- **中国：** 电商、支付、内容和本地生活平台一体化程度高，更容易在单一生态内闭环，也更容易由平台规则决定 Agent 的可见性与抽成。
- **创业客户：** 品牌商、连锁零售、中小商户、平台服务商、采购部门和支付／争议团队。
- **证伪：** 若机器发起交易占比、跨平台比价、商户获客费用、平台抽成和退货争议未发生结构变化，则行业主要仍是营销与客服优化。

## 六、行业四：制造、供应链与物流

### 原始结构与初始条件

制造业的知识流与物料流分离，使 Agent 能先改变计划和控制，后改变物理生产。入口包括研发设计、报价、排产、视觉质检、预测维护、采购、库存、能源和运输路线。OECD 认为现阶段采用仍有限且碎片化，规模化依赖数据、互操作和设备集成 [S77]。中国 2024 年工业机器人在用存量超过 200 万台，美国约 39.37 万台 [S78]；该差异说明中国更有条件让数字 Agent 接入物理执行，但不能直接推出单位资本效率更高。

### 四类结果与瓶颈

- **局部优化：** 单机质检、维护建议、文书和排程辅助，不改变产线节拍和供应链合同。
- **流程替代：** 从需求预测到采购建议、排产与物流协调形成闭环，人工处理例外；需要稳定主数据和可回滚权限。
- **企业重组：** 计划、采购、质量、设备与供应商管理职能合并，工厂管理跨度扩大；部分第三方计划与后台外包回流企业内部。
- **产业重构：** 柔性生产把小批量定制成本压低，产品生命周期缩短，制造能力可能以 API／按件服务方式出售；但设备、能源、良率、认证和供应商关系仍形成资本壁垒。

效率不是唯一目标。追求最低库存的 Agent 可能降低韧性，企业还要为地缘冲击、供应中断和质量责任保留冗余 [S89]。因此“最优 Agent”需同时优化成本、交期、韧性与合规，而非只压缩库存。

### 大小企业、中美差异与新产业

大型制造商拥有设备数据、供应商议价、资本和验证场景；中小厂可借轻量化模型、共享算力和行业数据服务降低固定成本。中国政策正在用行业联合体、高质量数据集和普惠算力弥补中小企业差距 [S86][S87]，但效果尚待验证。美国的机会更多在软件、系统集成、先进制造和本土供应链自动化；中国更可能在机器人、完整产业链、工业集群和地方示范中快速组合。

- **新行业：** 工业 Agent 集成、工厂语义层、设备数字身份、异常接管、合成训练数据、柔性制造市场、供应链情景推演。
- **客户：** 制造集团、专精特新企业、物流商、工业园区、设备商和系统集成商。
- **证伪：** 若 OEE、良率、换线时间、库存周转、交付波动、每厂计划人员和供应商数量没有持续改变，则大部分价值仍停留在数字化升级。

## 七、行业五：医疗、教育与养老

### 为什么“高暴露”不等于“高替代”

这些行业包含大量可数字化文书、解释和排程，同时又有高后果判断、许可、关系和身体照护。Agent 可先进入病历摘要、编码、预约、随访、患者导航、备课、反馈、行政排班和照护记录。OECD 报告所引的一项教师对照研究中，备课时间下降约 31%，但该报告同时指出，缺乏培训和互操作可能反而增加负担 [S80]。WHO 指南强调医疗数据、证据、偏差、责任和持续监督 [S81]。

### 四类结果的条件

- **局部优化：** 专业人员用 Agent 减少文书，节省时间被更多服务或更低加班吸收。
- **流程替代：** 低风险分流、常规随访、资格核验、课程练习和照护提醒形成机器主导流程，异常升级给专业人员。
- **企业重组：** 医生／教师／护理人员从亲自完成全部流程转为监督多个个案；机构需要新的质量控制和责任岗位。
- **产业重构：** 若支付和监管允许，服务从一次性就诊／课堂转为持续监测、个性化学习或居家照护协调；这会重新分配医院、学校、平台、家庭和保险／财政之间的职责。

核心限制不是模型“会不会回答”，而是错误由谁承担、服务质量如何衡量、弱势群体能否接入、面对面关系是否不可替代。Agent 若只扩大供给而支付预算固定，也可能增加待确认事项和专业人员负担，而不是节省成本。

### 中美差异、客户与验证

- **美国：** 医疗支付主体多、行政成本和专业工资高，自动化激励大；但责任、隐私、报销和系统碎片化提高集成门槛。教育市场分散，企业与地方采购形成多入口。
- **中国：** 公立医院、学校和地方政府具有集中部署能力，基层服务短缺形成需求；同时数据互通、地区财政和统一评估可能决定扩散速度。
- **创业客户：** 医疗集团、基层机构、学校／培训体系、养老运营商、政府购买服务部门。
- **证伪：** 应看每例专业人员分钟数、等待时间、再入院／学习结果、申诉和伤害率，而非只看问答次数。若结果不改善，节时不构成行业生产率。

## 八、行业六：内容、广告与文化

### 稀缺性从生产转向选择、身份与授权

Agent 显著降低文本、图像、音频和视频的版本化成本，最先替代的是素材变体、翻译、摘要、剪辑和投放测试，而非完整的文化需求。内容供给增加后，消费者时间不增加，故注意力、可信来源、人物身份、独特现场和社群关系成为更稀缺的资产。美国版权局已把数字复制、输出可版权性和训练使用分卷研究 [S84]，说明新利润池会围绕许可、来源证明和数字替身形成。

### 四类结果与市场结构

- **局部优化：** 创作者提高产量、营销和多语言能力，团队规模基本不变。
- **流程替代：** 批量广告素材、商品图、配音、短内容适配和低价委托由 Agent 完成。
- **企业重组：** 制作岗位减少，策划、审美、编辑、IP 管理、社区和品牌安全权重上升；经纪和工作室可能从“组织制作”转为“管理身份和授权”。
- **产业重构：** 个性化、互动式、持续生成内容成为产品；但供给爆炸可能把收入进一步推向拥有分发、品牌、角色 IP 和可信身份的一端。

生产端更可能碎片化，分发与身份权利更可能集中。小创作者获得生产能力，不代表获得注意力；大型平台节省内容成本，也面临虚假内容、低质泛滥和监管成本。新的客户需求包括内容来源证明、训练与输出许可、数字替身管理、品牌安全、机器生成内容筛选与创作者收益结算。

### 中美差异与证伪

- **美国：** 版权诉讼、工会合同、人物权利和全球娱乐 IP 使许可市场更关键。
- **中国：** 平台内容治理、生成合成标识和集中分发提高平台责任，商业化更依赖平台规则和品牌客户。
- **证伪：** 若人类原创溢价、内容单位价格、平台分成、版权许可收入、制作岗位和受众留存没有分化，则变化主要是制作工具升级。

## 九、行业七：农业、建筑与实体现场

### 物理世界把认知收益截断在哪里

农业和建筑的计划、估算、设计、采购、合规与监测可以数字化，但天气、地形、旧建筑、临时团队、安全和物理操作造成长尾异常。现有职业暴露研究显示，生成式 AI 对以认知、文字和行政任务为主的职业暴露更高；研究机构同时警告，暴露指标本身不能预测采用或岗位损失 [S55—S56]。这不是“物理行业没有影响”，而是 Agent 更可能先成为调度和认知控制层，物理替代取决于传感器、设备和机器人。

### 四类结果与组织后果

- **局部优化：** 投标、工程量、农情监测、材料计划、设备维护、安全文书和进度报告。
- **流程替代：** 标准化设计—报价—采购—调度闭环，或无人机／设备执行的重复巡检；人工处理现场例外。
- **企业重组：** 总包、分包、设备租赁和现场管理通过实时数据重新分工；远程专家可监督更多地点。
- **产业重构：** 建筑部件标准化、模块化施工、农业设备服务化和远程运营降低地域边界，但土地、资质、设备和本地响应仍使市场保持区域性。

大型企业更能承担设备、保险和数据固定成本，小企业可通过共享设备、租赁和垂直 Agent 获益。真正的新行业是“软件＋现场服务”的混合体：远程运营中心、设备编排、现场异常接管、机器可读工程合同、农业投入优化、传感器维护和安全证据服务。

### 中美差异、客户与证伪

- **美国：** 人工成本高、农场规模大、承包链分散，自动化回报高但责任保险和工会／许可差异形成州级摩擦。
- **中国：** 建筑和制造供应链密集、地方项目组织能力强；农业经营规模差异大，设备共享和地方服务网络比纯软件订阅更重要。
- **客户：** 总包与大型农场、设备商、保险与安全部门、地方农业服务和项目业主。
- **证伪：** 现场人工小时、事故、工期偏差、材料浪费、设备利用率和单位面积／项目利润若不改善，办公室自动化不能算产业重构。

## 十、行业八：公共管理与公共服务

### 公共部门的目标函数不同

政府不是只优化利润，还必须同时满足合法程序、公平、可解释、隐私、申诉和普遍服务。OECD 的 200 个政府用例中，57% 以自动化、简化或定制流程服务为主要目标；但遗留系统、技能、预算和更高问责要求拖慢采用 [S79]。因此最先变化的是高量低风险事务：查询、材料预审、翻译、案件分流、采购信息、欺诈线索和内部知识检索。

### 四类结果与制度后果

- **局部优化：** 公务员使用助手起草和检索，审批链不变。
- **流程替代：** 标准申请由 Agent 预填、校验、追踪和通知，人处理拒绝、例外与申诉。
- **组织重组：** 前台柜台、后台材料处理与专业审查重新组合；跨部门数据和统一身份成为关键基础设施。
- **制度重构：** 服务从“公民知道项目并主动申请”转为基于事件的主动触达；预算、采购、绩效和行政救济都要适应机器持续执行。

效率可能与信任冲突。若错误难以纠正或弱势群体被数据排除，自动化会增加申诉、线下补救和政治成本。公共采购还可能把关键能力锁定在少数云／模型供应商，或通过开放标准培育本地服务商。美国 2025 年政策强调快速采用、竞争采购和避免锁定 [S90]；中国“人工智能+”把公共治理和民生与产业应用并列 [S85]，更可能形成政府主导的跨场景试点。

### 客户、机会与证伪

- **客户：** 中央／联邦与地方部门、公共事业、法院与监管机构、政府 IT 承包商、审计与申诉机构。
- **机会：** 规则即代码、案件证据链、可申诉自动化、采购可移植性、公共服务可访问性、模型与数据审计。
- **证伪：** 应看处理周期、一次通过率、错误和申诉、线下补救、每案成本及群体差异。只有平均时间下降而申诉和不平等上升，不构成净公共生产率。

## 十一、跨行业的三条闭环

### 闭环 A：知识工作压缩—招聘入口—消费与培训

任务辅助提高初级工作产出 [S61][S74] → 企业减少补充招聘而非立即裁员 [S72] → 青年获得训练任务和第一份工作的机会减少 → 家庭支持和学历筛选的重要性上升 → 消费、迁移与家庭形成延后 → 政策和企业被迫创建学徒制、模拟任务和认证 → 培训成本部分抵消自动化收益。

### 闭环 B：上游集中—下游赋能—中型企业受压

芯片、云和模型上游集中 [S82][S83] → 通用能力按使用量向企业开放 → 小团队获得过去只有大企业拥有的专业生产能力 [S75] → 细分应用和微型企业增加 → 缺乏上游议价与细分差异的中型企业受压 → 并购、平台依赖和多云／开源政策上升 → 又反向影响上游集中度。

### 闭环 C：物理产业优化—资本开支—地区与能源

计划 Agent 与机器人／设备结合 [S77][S78] → 良率、停机和小批量成本下降 → 企业增加传感器、设备、算力和能源投资 → 收益先流向资本、设备商和数据基础好的地区 → 地区工资与财政分化 → 政府通过园区、算力、数据联合体和培训干预 [S86][S87] → 扩散速度和产业地理再次改变。

## 十二、创业机会不是“行业名单”，而是瓶颈的付费者

| 机会层 | 直接客户 | 为什么会付费 | 收益成熟条件 | 主要风险 |
|---|---|---|---|---|
| 流程发现与重写 | 中大型企业业务负责人、CIO、运营部门 | 个人工具已有，财务收益未出现 | 能用业务指标而非调用量证明效果 | 咨询项目化、难标准化 |
| Agent 权限与异常接管 | 高后果行业、平台、公共部门 | 无法律人格使责任仍在人／组织，需限制行动与留痕 | 接入真实系统并通过审计 | 被云和软件套件内建 |
| 行业数据与语义层 | 制造、医疗、供应链、政府 | 模型通用但企业数据碎片化 | 可复用连接器、标准和数据权利清晰 | 实施重、销售周期长 |
| 可验证结果与评测 | 采购、法务、审计、保险、监管 | 不能用演示替代生产证据 | 结果与损失、收入、质量相连 | 指标被博弈、责任扩大 |
| 中小企业 Agent 托管运营 | 中小商户、专业服务、制造小厂 | 无力自建团队但有营销、客服、采购和管理需求 | 低成本、行业模板和人工兜底 | 毛利薄、客户流失高 |
| 人机训练与岗位入口 | 大企业、人力资源、学校与政府 | 初级任务减少导致人才管道断裂 | 与招聘、晋升和认证绑定 | 预算常被视为非核心 |
| 机器可读商品／服务与交易 | 品牌、零售、平台、采购 | 消费与企业 Agent 需要可靠价格、库存、条款和身份 | 协议开放、争议机制成熟 | 平台封闭、标准割裂 |
| 现场 Agent＋服务网络 | 建筑、农业、物流、制造 | 纯软件无法处理物理异常 | 设备接入、保险、区域服务密度 | 资本密集、扩张慢 |

最稳健的机会不是押注“完全自主”，而是解决从任务演示到稳定生产之间的弱环节，并能明确回答谁承担错误、谁控制权限、谁为结果付费。

## 十三、当前判断与未知

- **已确认事实：** 企业 AI 采用正在扩散，但规模、行业和职能差异大；使用深度普遍浅；任务级收益可显著，但在完整交付链条中衰减；上游基础设施集中与中小企业轻量化赋能同时存在。
- **较强推断：** 未来两三年，变化更可能先表现为招聘放缓、外包回流、管理跨度扩大、产品数量增加和责任／审计岗位上升，而非全面裁员。
- **弱推断：** 中型通用软件和专业服务企业、低差异化内容制作与部分后台外包可能受到最大结构压力。
- **假设：** Agent 的可靠性、记忆、工具调用和受限预算继续改善，且单位成本下降快于治理与能源成本上升。
- **未知：** Agent 专门的企业利润、价格、并购、进入退出、争议损失和集中度数据尚不存在；中国小微企业与业务职能级公开调查不足；需求扩张能否抵消任务替代仍无法可靠量化。
